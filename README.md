# Task Tracker

Um aplicativo simples de **controle de tarefas** para organizar atividades do dia a dia.

## 📌 Sobre o projeto

O **Task Tracker** foi criado para ajudar no gerenciamento de tarefas de forma clara e objetiva, permitindo registrar, acompanhar e concluir atividades.

## ✨ Funcionalidades

- Criar novas tarefas
- Listar tarefas cadastradas
- Marcar tarefas como concluídas
- Remover tarefas

> Ajuste esta seção conforme as funcionalidades reais implementadas no projeto.

## 🛠️ Tecnologias

Este projeto utiliza o ecossistema **Node.js**.

- Node.js
- npm

## 🚀 Como executar o projeto

### Pré-requisitos

- [Node.js](https://nodejs.org/) instalado (versão LTS recomendada)
- npm

### Instalação

```bash
npm install
```

### Execução

```bash
npm start
```

### Ambiente de desenvolvimento (opcional)

```bash
npm run dev
```

## 🧪 Testes
